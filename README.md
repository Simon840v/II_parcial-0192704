 # Lotus & Co. - Flower Shop Frontend Web Page

Este proyecto consiste en la maquetación web accesible del diseño **Lotus & Co.** adaptada directamente a partir del prototipo gráfico de Figma.

## 🚀 Estructura del Proyecto

- **`index.html`**: Estructura semántica completa HTML5 que contiene el encabezado, navegación y las tres secciones principales del diseño (*Home*, *Orders*, *Contact Us*) más el pie de página.
- **`style/style.css`**: Hoja de estilos con variables de color, tipografía personalizada (`Playfair Display` y `Poppins`), diseño flexible (*CSS Grid* y *Flexbox*) y diseño responsivo para dispositivos móviles.
- **`assets/`**: Carpeta destinada a alojar los recursos visuales e imágenes del proyecto.

## 🎨 Paleta de Colores Utilizada

- **Home background:** `#f7d6e6` (Rosa claro)
- **Orders background:** `#9e9ee6` (Violeta claro)
- **Contact background:** `#8ed36b` (Verde suave)
- **Footer background:** `#92547a` (Púrpura rojizo)
- **Tarjetas destacadas:** `#fcf4c5` (Amarillo suave)
- **Banner de oferta:** `#a3dc96` (Verde menta)

## 🛠️ Cómo ejecutar en Visual Studio Code

1. Clona o copia esta carpeta en tu espacio de trabajo de Visual Studio Code.
2. Abre la extensión **Live Server** en VS Code.
3. Haz clic derecho sobre el archivo `index.html` y selecciona **"Open with Live Server"**.
